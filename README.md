# 🏦 Banking System

A command-line banking system built in Python using Object-Oriented Programming.
Built from scratch as a learning project — growing phase by phase.

## 🚀 Current Phase
**Phase 1 Complete** — Core banking operations via CLI

## ✅ Features
- Create a new bank account
- Deposit money
- Withdraw money  
- Check account balance
- Input validation and error handling

## 🛠️ Built With
- Python 3
- OOP (Classes, Objects, Methods)

## ▶️ How to Run
python main.py
